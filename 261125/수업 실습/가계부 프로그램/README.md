# 여행 가계부

여행 중 휴대폰에서 지출, 수입, ATM 인출을 기록하고 Google Sheets에서 합계를 확인하는 개인용 가계부입니다. Google Apps Script 웹 앱과 스프레드시트로 동작합니다.

## 주요 기능

- **거래 기록** — 소비·수입·ATM 인출 탭에서 날짜, 통화, 금액, 메모를 입력합니다. 날짜는 휴대폰 기준 오늘, 통화는 엔화가 기본입니다. 원화도 선택할 수 있습니다.
- **소비 분류** — 결제수단은 현금·카드 중 선택합니다. 기본 카테고리는 식비, 교통, 쇼핑, 장보기, 공과금입니다. 새 카테고리로 거래를 저장하면 다음 입력부터 다시 선택할 수 있습니다.
- **기간별 집계** — 통화별 전체·일별·월별 합계와 월별 카테고리 지출을 시트에서 확인합니다. 원화와 엔화는 각각 집계하며, ATM 인출은 인출 합계에만 반영합니다.
- **거래 정정** — 재입력으로 최근 거래를 불러와 수정합니다. 수정 전 기록은 이력으로 남고, 최신 유효 기록만 집계에 반영됩니다.
- **일일 한도** — 거래 날짜별로 소비·수입·ATM 인출을 합쳐 유효 기록을 최대 40건까지 저장합니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| [code.gs](./code.gs) | 거래 저장·정정, 삭제 처리, 시트 집계 |
| [index.html](./index.html) | 모바일 입력 화면과 저장한 행 바로가기 |

## 설치 및 배포

1. Google Sheets에서 새 스프레드시트를 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. 기본 `Code.gs`에 이 저장소의 `code.gs` 내용을 붙여넣습니다. 파일 상단의 `SPREADSHEET_ID`를 본인 시트 ID로 바꿉니다. 시트 주소의 `/d/`와 `/edit` 사이 값이 ID입니다.

   ```javascript
   const SPREADSHEET_ID = 'YOUR_SPREADSHEET_ID';
   ```

3. Apps Script 편집기에서 **파일 추가 → HTML**을 선택하고 이름을 `index`로 지정한 뒤, `index.html` 내용을 붙여넣습니다.
4. 두 파일을 저장하고, 함수 목록에서 `setupLedger`를 선택해 한 번 실행합니다. 권한을 승인하면 가계부에 필요한 시트 탭이 생성됩니다.
5. **배포 → 새 배포 → 웹 앱**을 선택합니다. 개인용으로 쓸 때는 **실행 사용자 → 나**, **액세스 권한 → 나만**으로 설정합니다. 배포 후 제공되는 웹 앱 URL을 휴대폰에서 엽니다.

코드를 수정한 뒤에는 **배포 → 배포 관리 → 기존 배포 수정 → 새 버전 → 배포**로 기존 웹 앱 주소를 갱신합니다.

## 구글시트 구성

| 탭 | 내용 |
| --- | --- |
| **가계부** | 상단에 통화별 전체 합계, 가운데에 날짜별 거래, 하단에 일별 합계 |
| **월별 요약** | 월별 지출·수입·ATM 인출 합계와 월별 카테고리 지출 |
| **카테고리** | 기본·사용자 추가 카테고리와 카테고리별 유효 지출 건수 |
| **거래 원본** | 모든 입력 내역, 결제수단, 수정 이력, 거래 상태 |

## 거래 수정과 삭제

- **수정** — 웹 앱에서 **재입력**을 체크하고 거래를 고릅니다. 내용을 고친 뒤 **수정 저장**을 누릅니다.
- **삭제** — `거래 원본` 탭에서 해당 행의 **I열(상태)**에 `삭제`라고 직접 입력합니다. 해당 거래는 이력에 남고, 집계·40건 한도·재입력 목록에서 제외됩니다. 카테고리 이름은 재사용할 수 있도록 남고, 유효 지출 건수만 줄어듭니다.

### 삭제 후 집계가 그대로일 때

- 시트의 **확장 프로그램 → Apps Script**에서 설치했다면, 저장된 코드의 `onEdit`가 시트 편집을 감지합니다.
- 별도로 만든 독립형 Apps Script 프로젝트는 편집기에서 `installLedgerEditTrigger`를 한 번 실행하고 요청된 권한을 승인해야 자동 갱신됩니다.
- 이미 삭제 표시를 한 거래나 자동 갱신이 실패한 거래는 편집기에서 `setupLedger`를 실행해 다시 집계할 수 있습니다. 실행 로그의 삭제 건수로 인식 여부를 확인할 수 있습니다.

## GitHub에 공개하기 전

업로드할 `code.gs` 복사본에서 실제 `SPREADSHEET_ID`를 `YOUR_SPREADSHEET_ID` 같은 예시 값으로 바꿉니다. 공개 저장소에는 소스 코드만 포함하고, 개인용 웹 앱 URL과 실제 거래 데이터는 별도로 관리합니다.
