# 11월 25일 저녁 신청 받기 프로그램

11월 25일 저녁 신청을 받는 수업 실습용 웹 앱입니다. 신청자가 이름과 먹고 싶은 음식을 제출하면 Google 스프레드시트에 응답이 한 줄씩 저장됩니다.

## 신청 방법

1. 배포된 웹 앱 주소에 접속합니다.
2. **이름**과 **음식**을 입력합니다. 두 항목은 필수이며 각각 최대 100자입니다.
3. **하고싶은말**은 필요한 경우에만 입력합니다. 최대 2,000자입니다.
4. **확인**을 누릅니다. 저장되면 ‘답장 감사합니다.’라는 메시지가 표시됩니다. 저장에 실패하면 안내 메시지가 나타나고 다시 제출할 수 있습니다.

## 설정 및 배포

1. Google 스프레드시트를 준비하고 하단에 **신청** 탭을 만듭니다. 빈 탭이라면 첫 응답이 저장될 때 헤더가 자동으로 만들어집니다. 이미 내용이 있는 탭을 사용한다면 A1, B1, C1을 각각 `이름`, `음식`, `하고싶은말`로 맞춥니다.
2. Google Apps Script 프로젝트를 만들고 스크립트 파일에 `code.gs`의 내용을 붙여 넣습니다. HTML 파일을 `index`라는 이름으로 추가하고 `index.html`의 내용을 붙여 넣습니다.
3. 스크립트의 `SPREADSHEET`에 사용할 스프레드시트 URL 또는 ID를 입력합니다. 응답 탭 이름을 바꿨다면 `SHEET_NAME`도 같은 이름으로 수정합니다.
4. Apps Script 편집기에서 `testConnection`을 실행합니다. 처음 실행할 때는 권한을 승인하고, 실행 로그에서 **시트 연결 및 헤더 확인 완료**가 표시되는지 확인합니다.
5. **배포 → 새 배포 → 웹 앱**을 선택합니다. 실행 계정은 응답 시트에 쓸 수 있어야 합니다. 배포 계정으로 응답을 저장하려면 **다음 사용자로 실행**에서 **나**를 선택하고, **액세스 권한이 있는 사용자** 범위를 신청 대상에 맞게 설정합니다.
6. 배포 후 발급된 웹 앱 주소를 열어 테스트 응답을 보냅니다. 완료 메시지와 **신청** 탭에 새 행이 추가됐는지 확인합니다.

신청 화면은 Apps Script의 `google.script.run`을 사용하므로 제출을 테스트할 때는 Apps Script에서 발급한 웹 앱 주소로 접속합니다.
